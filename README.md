# FAQ-бот для Telegram

Telegram-бот, который отвечает на частые вопросы пользователей и рассказывает о проекте. Для администраторов предусмотрена закрытая админ-панель.

> **Важно.** Ответы на вопросы в боте вымышлены: проект создан как часть портфолио разработчика.

## Возможности

- Приветствие и краткий рассказ о том, что умеет бот.
- Клавиатура с частыми вопросами: пользователь нажимает на кнопку и получает готовый ответ.
- Админ-панель, доступная только администраторам.

## Команды

| Команда  | Кто может использовать | Что делает |
|----------|------------------------|------------|
| `/start` | Все пользователи | Приветствует пользователя, рассказывает о боте и показывает клавиатуру с частыми вопросами |
| `/admin` | Только администраторы | Открывает админ-панель. Остальным пользователям команда недоступна |

Администраторы определяются по Telegram ID из переменной `ADMIN_USERS` в файле `.env`.

## Стек

- Python 3.10+
- aiogram 3
- SQLite3

## Структура проекта

```
my_bot/
├── src/
│   ├── main.py          # запуск бота
│   ├── config.py        # загрузка настроек из .env
│   ├── handlers/        # обработчики команд (start, admin)
│   ├── keyboards/       # reply- и inline-клавиатуры
│   ├── database/        # подключение к БД, модели, запросы
│   ├── middlewares/     # промежуточные обработчики (например, антиспам)
│   ├── filters/         # собственные фильтры (например, проверка на админа)
│   └── utils/           # вспомогательные функции
├── tests/
├── .env.example         # пример файла с настройками
├── requirements.txt     # зависимости проекта
└── README.md
```

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <ссылка на репозиторий>
   cd my_bot
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Linux / macOS
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе `.env.example` и заполните его (см. раздел ниже).

5. Запустите бота из корня проекта:

   ```bash
   python -m src.main
   ```

## Настройка

Все настройки хранятся в файле `.env`. Этот файл содержит секреты, поэтому его нельзя публиковать в репозитории.

| Переменная    | Описание | Пример |
|---------------|----------|--------|
| `BOT_TOKEN`   | Токен бота, полученный у [@BotFather](https://t.me/BotFather) | `123456:ABC-DEF...` |
| `ADMIN_USERS` | Telegram ID администраторов через запятую | `123456789,987654321` |
