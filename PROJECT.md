# PROJECT: FAQ-бот для Telegram

## 1. Цель
Одно-два предложения: зачем нужен проект и что получится в итоге.
(Например: бот для портфолио, который показывает умение работать с aiogram, FSM и разделением кода на слои.)

## 2. Границы
**Входит в первую версию (MVP):**
- /start с приветствием и клавиатурой частых вопросов
- ответ на нажатие кнопки
- /admin, доступная только ID из ADMIN_USERS

## 3. Сценарии пользователя
1. Пользователь пишет /start → видит приветствие и кнопки.
2. Нажимает на вопрос → получает ответ, есть кнопка «Назад».
3. Админ пишет /admin → видит панель. Обычный пользователь → вежливый отказ.

## 4. Структура и ответственность файлов
my_bot/
├── src/
│   ├── main.py          # запуск бота
│   ├── config.py        # загрузка настроек из .env
│   ├── handlers/        # обработчики команд (start, admin)
│   ├── keyboards/       # reply- и inline-клавиатуры
│   ├── database/        # подключение к БД, модели, запросы
│   ├── middlewares/     # промежуточные обработчики (например, антиспам)
│   ├── filters/         # собственные фильтры (например, проверка на админа)
│   └── utils/           # вспомогательные функции
├── tests/
├── .env.example         # пример файла с настройками
├── requirements.txt     # зависимости проекта
└── README.md
└── PROJECT.md           # Обязательно к прочтению ИИ для выполнения задач

## 5. Этапы

- [ ] Этап 2: клавиатура и ответы на вопросы
- [ ] Этап 3: фильтр IsAdmin и /admin
- [ ] Этап 4: .env.example, README, оформление
- [ ] Этап 5: база, статистика, антиспам

## 6. Принятые решения
- aiogram 3, Python 3.10+
- админы определяются по Telegram ID, а не по username
- тексты вопросов и ответов лежат в одном месте, чтобы легко менять
